# Clash Verge CLI

使用本机已安装的 Clash Verge Rev/Mihomo 诊断受限网络，并在授权范围内查询或管理代理。优先使用应用内置 CLI 与运行中核心的 Unix socket；用户没有要求时不操作 Clash GUI。

## 路由

- 诊断网络失败、查询状态、确认当前节点、查看连接或测试延迟：完整读取 [references/diagnostics.md](references/diagnostics.md)。
- 更新 FIB 或其他阅后即焚订阅：先完整读取 `diagnostics.md`，再完整读取 [references/subscription-update.md](references/subscription-update.md)，并在取得一次性 URL 前完成盘点、备份方案和校验准备。
- 切换节点或 mode、启停 TUN/系统代理、替换配置、重载核心：读取任务相关 reference，并在动作发生前确认用户已经明确授权。
- 远程服务器 VPN/WireGuard 部署、公司网络准入、浏览器账号登录或普通网站页面错误：不要使用本 Skill 代替对应工作流。

## 工作原则

1. 先判断是网络路径问题还是目标服务、DNS、证书、认证、限流或项目配置问题；不要把所有连接失败都归因于“需要梯子”。
2. 先做只读发现：系统、进程、内核版本、配置目录、controller、mode、TUN、mixed-port 与关键策略组。
3. 对下载或开放网页访问问题，比较当前路径与显式本地代理路径；使用每条命令的临时代理参数，不永久写入项目或 shell 配置。
4. Rule 模式下同时报告关键 Selector 与活动连接的真实出口；不能只看 `GLOBAL`。
5. 延迟测试说明测试目标、超时、时间和成功/失败数；不要把延迟称为带宽测速。
6. 订阅余额优先采用服务商实时页面或当前响应头；本地缓存与核心累计流量必须注明口径和时间。
7. 更新订阅必须执行下载到临时目录、内容比较、双重校验、备份、原子替换、热重载、验收和失败回滚。

## 授权边界

- 可主动执行：版本、配置、策略组、连接、日志、流量元数据和延迟等只读查询；为当前只读请求使用单条命令的临时代理。
- 必须明确授权：切换节点/mode、启停 TUN 或系统代理、修改持久代理环境、更新订阅、覆盖配置、关闭连接、重启或热重载核心。
- 不要安装新的 VPN/代理软件，除非用户另行明确要求。

## 敏感信息

- 把订阅 URL、阅后即焚 TOKEN、代理密码、Reality 密钥、controller secret、账号邮箱与用户 IP 当作敏感凭据。
- 不在对话、命令输出、DOM snapshot、日志或 diff 中暴露这些值；比较代理配置时只输出节点名称、计数和变化字段名。
- 复制阅后即焚链接后，不读取可能包含隐藏 URL 的完整 DOM，也不读取包含 TOKEN/IP 的完整订阅记录表。
- 临时目录使用 `0700`，敏感文件使用 `0600`；验证完成后删除本次精确临时目录并保留受限权限的时间戳备份。

## 交付

报告诊断结论、当前 mode/TUN、关键策略组与真实活动出口、采用的验证证据，以及是否修改了任何状态。更新任务还要报告校验结果、热重载状态、连通性验收、备份位置和一次性链接是否已经失效；绝不回显凭据。
