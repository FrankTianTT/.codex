# ibm5100 魂+ 合集解压

## 概述

魂+ 用户 ibm5100 发布的同人志合集，分发方式为：百度网盘链接 → RAR v5 压缩包（双层） → 按社团/画师组织的文件夹。

## 文件结构

### Layer 0: 链接文件

- 小 `.rar` 文件，如 `合集7558.rar`（~500 字节）
- 密码：`uohsoaixgnaixgnawab`
- 内含一个 `.txt`，记录百度网盘 URL + 4 位提取码

### Layer 1: 百度网盘下载

- 大文件（5-10 GB），**无文件扩展名**
- 格式：`file` 命令显示 `RAR archive data, v5`
- 命名规则：`soul-ibm5100-XXXX-YYYYMMDD` 或 `soul-ibm5100-XXXX-YYYYMMDD-neo`
- 部分文件拆分到子目录：
  - `soul-ibm5100-XXXX-part1`、`soul-ibm5100-XXXX-part2`……

拆分部分需先合并：`cat /path/to/parts/* > combined`

### Layer 2: 同名内层 RAR

解压 Layer 1 得到一个**与原名相同的**文件，同样是 RAR v5。用相同密码再解压一次，得到实际内容。

### 最终目录结构

```
合集ID-[社团名 (画师名)]/
  ├── 1. 同人志/        # 按展会 (CXX/COMIC1/etc.) 整理
  │   ├── (C100) 作品名 [汉化组]
  │   ├── (C100) 作品名 [英訳]
  │   └── (C100) 作品名               # 日文原版
  ├── 2. 商业志/         # 商业杂志
  ├── 3. 单行本/         # 合订本
  ├── 4. 画集/           # 画集/插画
  ├── 5. CG/             # 数字 CG
  └── 防盗链...txt
```

## 解压流程

### 1. 提取链接

```bash
mkdir -p /tmp/rar_links
for f in /path/to/合集*.rar; do
  unar -p "uohsoaixgnaixgnawab" -o /tmp/rar_links "$f"
done
```

### 2. 选择存储目标

**关键**：必须用本地 SSD 或直连 USB 盘，**禁止解压到 NAS**。10GB+ 的 RAR 解出几千个小图片，NAS I/O 不可接受。

```bash
df -h /Volumes/EXTERNAL_DRIVE
```

### 3. 双层并行解压

```bash
PASS="uohsoaixgnaixgnawab"
TMP="/Volumes/EXTERNAL/tmp"
OUT="/Volumes/EXTERNAL/extract"

extract_one() {
  local src="$1" label="$2"
  local d="$TMP/$label"
  mkdir -p "$d"

  # Layer 1 → 同名内层 RAR
  if ! unar -p "$PASS" -o "$d" "$src"; then
    echo "Layer 1 failed: $src" >&2
    return 1
  fi

  # Layer 2 → 实际内容
  local inner
  inner=$(find "$d" -maxdepth 1 -type f -iname '*.rar' -print -quit)
  if [ -z "$inner" ]; then
    echo "No inner RAR: $src" >&2
    return 1
  fi
  if ! unar -p "$PASS" -o "$OUT/$label" "$inner"; then
    echo "Layer 2 failed: $inner" >&2
    return 1
  fi

  # 不自动删除 $d。完成第 4 步文件数/抽样验证后，再把临时目录移入废纸篓。
}

# 并行启动（9 路对 USB 盘友好，~20-30 分钟处理 80GB）
extract_one "/path/to/file1" "label1" &
extract_one "/path/to/file2" "label2" &
wait
```

### 4. 验证

```bash
for d in "$OUT"/*/; do
  echo "$(basename "$d") — $(find "$d" -type f | wc -l) files"
done
```

## 解压陷阱

1. **NAS 解压 = 灾难** — 用本地 SSD，不要跨网络
2. **提前检查磁盘空间** — 10GB RAR → ~15GB 双层解压后
3. **残留进程** — 先检查具体 PID 和任务归属，再终止准确的进程；不要使用宽泛的 `pkill -9 -f`。
4. **用 unar 不是 unrar** — macOS Homebrew 提供的是 `unar`
5. **拆分 part 必须先 cat** — `-part1` `-part2` 不是标准 RAR 分卷
6. **密码全一样** — 链接 .rar 和内容 .rar 都是 `uohsoaixgnaixgnawab`
7. **双层结构是固定的** — RAR v5 → RAR v5 → 内容，不存在其他变体

## 解压后

解压完成后回到主 SKILL.md 的流程：语言分类 → 去重 → 重组 → 压缩。

迁移到 NAS 使用：
```bash
uv run python3 scripts/migrate_to_nas.py             # 默认预览
uv run python3 scripts/migrate_to_nas.py --execute   # 确认预览后执行
```

## 快速命令

```bash
# 检测扩展名缺失的文件类型
file /path/to/ibm5100-archive-*

# 解压链接 .rar
unar -p "uohsoaixgnaixgnawab" -o /tmp/out "合集XXXX.rar"

# 合并拆分 part
cat part1 part2 part3 > combined

# 单文件双层解压
unar -p "uohsoaixgnaixgnawab" -o /tmp/layer1 file
unar -p "uohsoaixgnaixgnawab" -o /tmp/final /tmp/layer1/innerfile
```
